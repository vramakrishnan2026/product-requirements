# Glossary (for asking questions consistently)

- **Relay output**: switched contact driving equipment (fan speeds, compressor, valves). Ask quantity and rating.
- **Analog output (AO)**: modulating signal, usually 0–10 V, to valves/dampers/VFDs.
- **Analog input (AI)**: measured signal (0–10 V, 4–20 mA, thermistor).
- **Universal input (UI)**: input that can be configured as several types; ask which combinations must be supported.
- **RS-485**: wired serial bus. Protocols on it: Modbus RTU, BACnet MS/TP.
- **Ethernet / IP**: Modbus TCP/IP, BACnet/IP, BACnet/SC (secure connect).
- **RF**: wireless link, typically to the CCU or other field devices.
- **CCU**: central control unit that coordinates zone devices.
- **Standalone**: device runs its control application on its own.
- **Failsafe-only standalone**: device runs a reduced/safe mode only when it loses the CCU.
- **Profile**: the control application, e.g. 2-pipe FCU, 4-pipe FCU, conventional package unit (CPU), heat pump unit (HPU). Ask whether standard or with exceptions.
- **Low-code**: logic built in the Site Sequencer (Blockly-style blocks) instead of fixed firmware.
- **OTA**: over-the-air firmware update (via RF, Bluetooth, IP or USB).
- **Plastics reuse**: reusing an existing product family's enclosure to save tooling cost.
- **BOQ**: bill of quantities (parts list with costs), used later for cost estimates.
